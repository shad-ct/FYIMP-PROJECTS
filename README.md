# FYIMP Workspace

This branch holds the study material snapshot.
The `main` and `code` branches are index-only branches, while `files` contains the semester resources.

## Branch Guide

| Branch | What it contains |
| --- | --- |
| `main` | README only, used as the primary branch index |
| `code` | README only, used as a secondary branch index |
| `files` | README plus the SEM05 material tree |

## Move Between Branches

```bash
git branch
git switch main
git switch code
git switch files
```
